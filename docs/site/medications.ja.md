# 服薬記録

Mirobody は服薬プランを測定値とは別に保存します。プランは意図した使い方を表し、服用ログは本人が服用した、または服用しなかったと記録した内容です。

## プランを追加して確認する

名前・用量・頻度を含めて、日記に服薬の記録をつけます。たとえば「サンプル薬、1日2回1錠」のように、架空の薬名で記録できます。できあがったプランは**指標 › 服薬**で確認し、必要に応じて修正してください。認識できない用法はそのまま文章として残り、不完全なスケジュールとして推測されることはありません。

服薬を中止すると、現在の服用期間が終了します。再開すると新しい服用期間が始まり、履歴はそのまま保持されます。日記から作成したプランを削除すると、その記録は入力誤りとして扱われます。

## 服薬データを問い合わせる

| `query_medications` のビュー | 用途 |
| --- | --- |
| `plan` | 指定した期間内に有効だったプラン。 |
| `log` | 服用または未服用として記録された内容。既定では直近30日間（当日を含む）。 |
| `history` | 服用期間とその日付、終了理由。 |

`keywords`、`start`、`end` で問い合わせを絞り込めます。

```python
query_medications(view="plan", keywords=["<記録されている薬名>"])
query_medications(view="log", start="2026-10-01", end="2026-10-21")
```

プランがあることは、実際に服用した証拠にはなりません。ログに記録がないことも、服用しなかった証拠にはなりません。服用予定・今後の予定・飲み忘れの状態は時刻と記録済みの出来事によって決まり、本人がログを更新すると変わることがあります。

## API 連携

アプリケーションはプラン管理機能を `/api/v1/medications` で公開しています。書き込みには本人の権限か、家族との共有での書き込み権限が必要です。閲覧のみの権限では変更できません。現在のリクエストの形式は、デプロイ先の `/docs` で確認してください。

服薬のデータモデルはまだ provisional（暫定）です。スケジュールの文法、状態遷移、FHIR の詳細が必要な開発者は、[服薬の技術リファレンス](../medications.md)（英語）を参照してください。
