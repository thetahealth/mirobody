# Apple Health

iOS の「ヘルスケア」App からの書き出しをインポートするか、認可済みのクライアント App から HealthKit の記録を送信します。Apple Health は、デバイスのクラウドサービスのようなサーバー側 OAuth 連携を提供しません。

## 書き出しをインポートする

「ヘルスケア」で自分のプロフィールを開き、「すべてのヘルスケアデータを書き出す」を選びます。
基本の Python パッケージだけで、モデルやデータベースなしにこのアーカイブを読み取れます。

```bash
mirobody import apple export.zip
```

特定の人の記録に保存するには、サーバー設定を持つアプリケーションのインストールを使います。

```bash
mirobody import apple export.zip --into <user-id>
```

同じアーカイブを再インポートしても、コピーが増えることはありません。書き出しデータとスマートフォンからの送信が重なる期間は、1日ごとの集計が一方の出どころを選び、両方を足し合わせることはしません。

## クライアント連携

認証済みのクライアントは、HealthKit の JSON を `POST /apple/health` に送信できます。
`HKQuantityTypeIdentifierHeartRate` のような Apple の識別子を使い、各レコードの元の単位を `startDate`・`endDate` とともに送ってください。

- 日付はミリ秒単位のエポック時刻か、オフセット付きの Apple の日付文字列で指定します。
- 割合を表す量は小数で表します。酸素飽和度 98% は `0.98` です。
- 分類値には対応する `HKCategoryValue*` 文字列を使います。
- クライアントは、リアルタイム送信の前に重複を取り除いてください。

CDA 文書はアプリケーションの CDA インポート経路を使います。
対応する種類、リクエスト例、検証の挙動は[Apple Health リファレンス](../apple-health.md)（英語）にあります。
