# 新しいデータソースを追加する

データソースはデバイスサービスと Mirobody をつなぎます。新しく書く前に、既存の連携やファイル取り込みがそのデータソースにすでに対応していないか確認してください。

## 実装の約束事

デコードとネットワークアクセスは分けてください。デコーダーはベンダーのペイロードを対応済みの指標に変換し、データソース側は認証情報・リクエスト・コールバック・同期を担当します。

データソースの約束事は次のとおりです。

- `format_data(self, fmt_input: FormatDataInput) -> StandardPulseData`
- `_validate_credentials(self, credentials: dict)`

設定は設定システム経由で読み込んでください。認証情報が欠けているオプションの連携は、利用可能なデータソースとして登録すべきではありません。
観測データの書き込みはすべて共有の収集経路を通す必要があり、デコードした値の単位はカタログの単位が基準になります。

## 登録する

自分のデータソース用ディレクトリを `PROVIDER_DIRS` に追加します。既定の項目は残したままにします。

```yaml
PROVIDER_DIRS:
  - mirobody/collect/providers
  - my_providers
```

インストール済みのパッケージは、`mirobody.providers` のエントリーポイントからも登録できます。
実際のアカウントを接続する前に、合成データを使って単位変換、タイムスタンプの扱い、欠落フィールド、重複した配信、認証失敗への対応を確認してください。ログに測定値や認証情報を残してはいけません。

[実装ガイド](../provider-guide.md)（英語）には、完全なクラスの例、OAuth と Webhook の処理、デコーダーの例、登録の詳細が載っています。
既存の連携については、[デバイスサービスへの接続](../provider-setup.md)（英語）を参照してください。
