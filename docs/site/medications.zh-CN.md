# 用药记录

Mirobody 将用药计划与测量指标分开保存。计划表示打算怎样用药，服药日志表示用户记录过的
已服或跳过情况，两者不能互相替代。

## 添加与核对

在日记中填写药名、每次用量和频次，例如使用虚构药名记录“示例药，每天两次，每次一片”。
随后到**指标 › 用药**核对并更正计划。无法识别的用法保留为原文，不会猜测出一份不完整的时间表。

停药会结束当前疗程，恢复用药会创建新疗程，历史记录仍然保留。
移除日记创建的计划时，该记录会被标记为录入有误。

## 查询记录

| `query_medications` 视图 | 用途 |
| --- | --- |
| `plan` | 指定时间范围内生效过的用药计划。 |
| `log` | 已记录的服药或跳过情况，默认查询最近 30 天（含今天）。 |
| `history` | 疗程起止时间和结束信息。 |

使用 `keywords`、`start`、`end` 限定查询：

```python
query_medications(view="plan", keywords=["<记录中的药名>"])
query_medications(view="log", start="2026-10-01", end="2026-10-21")
```

计划不代表实际服药，日志里没有某次记录也不代表没有服药。
待服、到期、漏服等状态随时间和用户补记而变化。

## API 接入

计划管理接口位于 `/api/v1/medications`。修改需要本人权限，或关爱圈成员的写入授权；
只有读取权限时不能修改。具体请求格式以部署服务的 `/docs` 为准。

用药数据模型目前仍属 provisional。时间表语法、状态转换和 FHIR 导入规则见[用药技术参考](../medications.md)。
