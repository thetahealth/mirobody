# 健康データツール

内蔵エージェントと認証済みの MCP クライアントは、選択した本人の記録に問い合わせます。
アカウントの身元はセッション・トークン・個人リンクから渡されるもので、モデルが指定するツール引数ではありません。

## ツールを選ぶ

| ツール | データ |
| --- | --- |
| `query_health_indicators` | 測定値、記録された症状と診断。 |
| `query_medications` | 服薬プラン、記録済みの服用状況、服用期間の履歴。 |
| `query_genetic_data` | 部位・遺伝子・領域ごとの遺伝子型判定。 |
| `query_pharmacogenomics` | CPIC の薬物と遺伝子の対応状況。 |
| `resolve_indicator` | オフラインでの指標名の解決。 |
| `normalize_unit`、`convert_unit` | オフラインでの単位の正規化と換算。 |

アカウントに該当するデータが1つもない場合、MCP はその記録ツールを表示しません。
医学知識ツールは任意で、本人の記録ではなく一般的な情報源を検索します。
[MCP の設定](https://docs.mirobody.ai/ja/tools/mcp-integration)を参照してください。

## 測定値を読む

まず名称を調べ、次に必要なビューで問い合わせます。

```python
query_health_indicators(keywords=["cholesterol"])
query_health_indicators(indicators=["<結果から得た名称>"], view="latest")
```

| ビュー | 結果 |
| --- | --- |
| `raw` | 個々の測定値。 |
| `minute`、`hour`、`day`、`week`、`month` | 時間帯ごとの集計。 |
| `stats` | 件数、最小値、最大値、平均、合計、最初と最後の値、変化量。 |
| `latest` | 指標ごとの最新値。 |
| `trend` | 期間内の変化の方向と形態。データが比較できない場合は理由を示します。 |

`keywords` も `indicators` も指定しない場合、ビューを指定していてもカタログが返ります。
`start` と `end` は記録の持ち主のタイムゾーンでの、両端を含む日付です。たとえば「直近7日間」は6日前から始まります。
測定値の日付を指定しなければ、記録全体が対象になります。

## 結果を読み取る

結果にはステータス（`ok`、`partial`、`error`）、日付の範囲、ビュー、出どころ、前提が示されます。
結果が切り詰められている場合、それは履歴の全体ではありません。範囲を絞るか、適切な集計ビューを使ってください。
日次以上の粗いビューは日数単位で集計するため、平均値が個々の測定値から計算した統計と異なることがあります。

データがないことは記録がないことを意味するだけで、その状態がないという証拠にはなりません。
結果を引用または計算に使うときは、返された行 ID を保持してください。追加の計算には[計算ツール](../python-analysis.ja.md)を使います。
完全なスキーマと結果の規約は[ツールリファレンス](../answers.md)（英語）にあります。
