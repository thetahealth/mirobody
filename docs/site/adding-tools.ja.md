# ツールを追加する

インストール済みの Mirobody パッケージを変更せずに、Python のツールを追加できます。設定したモジュールをエンジンが検出し、そのツールをエージェントと MCP クライアントに公開します。

## モジュールを作成する

型ヒントと分かりやすい docstring を付けた関数を、自分のツール用ディレクトリに保存します。

```python
# my_tools/arithmetic.py
__tools__ = ("add_numbers",)


def add_numbers(a: float, b: float) -> dict:
    """2つの数を足します。

    Args:
        a: 1つ目の数。
        b: 2つ目の数。
    """
    return {"sum": a + b}
```

設定の上書きファイルにそのディレクトリを登録します。組み込みのパスは残したままにします。

```yaml
MCP_TOOL_DIRS:
  - mirobody/agent/tools
  - my_tools
```

アプリケーションを再起動すると読み込まれます。MCP クライアントから `tools/list` を確認してください。
`_` で始まるファイルは無視されます。クラスを使う場合は名前の末尾を `Service` にします。`__tools__` を使うと、公開するメソッドを明示的に限定できます。

## 身元とアクセス権

認証済みの記録コンテキストが必要なツールは、`user_info` を宣言できます。これはエンジンが注入するもので、モデルが指定する引数としては公開されません。データの読み書きの前に、記録の所有者とアクセス権限を必ず確認してください。モデルが渡すユーザー ID を認可の根拠にしてはいけません。

健康記録を扱うときは、共有の観測データ書き込み機能と統一されたクエリの仕組みを使ってください。個人の値やベンダーの例外メッセージをログに残さないでください。
パッケージのエントリーポイント、引用、完全な例については、[ツール開発リファレンス](../../mirobody/agent/tools/README.md)（英語）を参照してください。
